# Lunaris AOSP – Miatoll

This repository contains the setup script for building **Lunaris AOSP** on the Xiaomi Miatoll series.

---

## 🚀 Quick Start

To set up your build environment and start the sync/build process, just run:

```bash
crave run --no-patch -- "curl https://raw.githubusercontent.com/MaheshTechnicals/local_manifests_miatoll/refs/heads/lunaris/lunaris.sh | bash"
